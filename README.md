Браузерная игра на React и TypeScript с собственной игровой логикой и отрисовкой на Canvas 2D.

Ретро-шутер в интерфейсе Game Boy Advance: игрок управляет модулем защиты внутри заражённого сервера. Нужно уничтожить угрозы и добраться до зелёного выхода на миникарте. Образы вирусов: Червь, Шифровальщик и Троян (+ босс Madman) — игровая интерпретация, а не модель работы антивируса.

## Стек

React 17 · TypeScript · Canvas 2D · Web Audio API · Less / CSS Modules · Webpack · Vitest · ESLint · Prettier.

## Основа проекта

В качестве основы использован готовый стартовый шаблон React / TypeScript с настройками Webpack, ESLint и Prettier.

Поверх этой основы реализовано игровое приложение: интерфейс консоли, управление, игровой мир и боевые механики, Canvas-отрисовка и звук. В текущую версию также входят unit-тесты на Vitest, скрипты подготовки статических ресурсов и локального просмотра production-сборки, документация по настройке игры.

## Запуск

Для локального запуска нужны Node.js и npm. Исходная версия проверялась с Node.js 23.11.0 и npm 10.9.2.

```sh
npm ci
npm run dev
```

Игра доступна на http://localhost:8080. Звук выключен при запуске; его можно включить кнопкой под консолью.

## Сборка и проверки

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

`build` создаёт production-сборку в `dist`, включая изображения из `public`. `preview` открывает локальный сервер сборки на http://127.0.0.1:8081. Для запуска используйте HTTP-сервер, а не открытие index.html двойным кликом. `npm run format` форматирует исходники с Prettier.

## Публикация

GitHub Actions запускает линтер, проверку типов, тесты и production-сборку. При успешном обновлении ветки `main` сборка публикуется на GitHub Pages; для pull request выполняются только проверки и сборка.

Для первоначального включения хостинга выберите **Settings → Pages → Build and deployment → Source → GitHub Actions** в настройках репозитория. После этого отправьте коммит в `main` или запустите workflow **Check and deploy GitHub Pages** вручную во вкладке Actions.

Ресурсы используют относительные пути, поэтому сборку можно размещать как в корне сайта, так и в подпапке `/sector-503/`.

## Управление

| Действие | Клавиатура | Кнопки консоли |
| --- | --- | --- |
| Движение вперёд / назад | W / S или ↑ / ↓ | Крестовина вверх / вниз |
| Поворот | A / D или ← / → | Крестовина влево / вправо |
| Стрельба | Пробел | A (можно удерживать) |
| Пауза | Esc | B |
| Начало / продолжение | Кнопка на экране | Start |
| Перезапуск | Кнопка в меню паузы | Select, только на паузе |

Кнопки поддерживают мышь, касания и клавиатурный фокус. При уходе со страницы или потере фокуса игра автоматически ставится на паузу. На узком экране удобнее альбомная ориентация.

## Игровые механики

- Один уровень, семь обычных врагов трёх типов: червь, троян и шифровальщик.
- Противники замечают игрока в пределах прямой видимости и атакуют снарядами. Стены блокируют движение и выстрелы.
- Три аптечки восстанавливают по 35 единиц защиты; при полной защите не расходуются.
- Две секретные комнаты скрыты за чуть более тёмными разрушаемыми стенами. В одной — трофей, в другой — лазер с уроном 2 вместо 1.
- Подбор лазера вызывает босса Madman с 12 единицами здоровья.
- Победа — устранены все появившиеся враги и достигнут выход. Секреты необязательны, но вызванного босса тоже нужно победить. Проигрыш — защита упала до нуля.

## Реализация

Игра работает в браузере без отдельного backend. Игрового движка и библиотеки 3D-графики нет. Node.js используется для инструментов разработки и локального HTTP-сервера статических файлов.

React отвечает за корпус консоли, кнопки, меню и показатели. Игровой цикл работает через requestAnimationFrame, состояние мира хранится в ref. Canvas 2D рисует псевдотрёхмерную сцену методом ray casting: лучи обходят сетку карты алгоритмом DDA, а глубина стен используется для скрытия спрайтов. Звук и музыка синтезируются через Web Audio API.

| Файлы | Назначение |
| --- | --- |
| `src/components/App/` | Интерфейс, ввод, игровой цикл, расположение деталей консоли |
| `src/game/level.ts`, `config.ts`, `enemy-types.ts` | Карта, баланс и поведение врагов |
| `world.ts`, `combat.ts`, `enemy-movement.ts`, `projectiles.ts`, `items.ts` | Движение, столкновения, бой и предметы |
| `raycast.ts`, `render.ts`, `sprites.ts`, `images.ts`, `texture.ts` | Отрисовка и загрузка текстур |
| `audio.ts`, `sound-config.ts` | Музыка и звуковые эффекты |
| `public/textures/` | PNG корпуса, кнопок, врагов и предметов |

В проекте 30 unit-тестов в 7 файлах. Тесты проверяют пересечения лучей, препятствия, урон и перезарядку, паузу, победу и поражение, предметы, поведение врагов и загрузку спрайтов. Unit-тесты используют фиксированную карту; отдельно проверяется корректность актуального уровня.

## Визуальные материалы и ограничения

PNG врагов и предметов подготовлены для проекта по собственным эскизам. Корпус и кнопки консоли собраны в Illustrator на основе изображения Game Boy Advance. Nintendo и Game Boy — обозначения оригинальной консоли; проект не связан с Nintendo. При отсутствии необязательной текстуры используется программно нарисованная графика.

У врагов нет поиска пути вокруг препятствий; движение ограничено простыми настраиваемыми режимами. Сохранения прогресса нет. Интерфейс масштабируется вместе с корпусом, поэтому на небольшом экране игровое окно тоже уменьшается.

Подробности редактирования карты, поведения, текстур и звука находятся в [документации по настройке](docs/configuration.md).
